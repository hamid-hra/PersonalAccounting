# نرم‌افزار حسابداری شخصی

وب‌اپلیکیشن محلی برای وارد کردن صورتحساب بانکی، فهمیدن اینکه پول کجا خرج
می‌شود، و مدیریت وام، قرض و دارایی.

همه‌چیز روی همین رایانه اجرا می‌شود؛ هیچ داده‌ای بیرون نمی‌رود.

---

## راه‌اندازی

```bash
docker compose up -d --build
```

سپس در مرورگر: **<http://localhost:8080>**

**اول وارد شو، بعد از صفحهٔ تنظیمات رمز را عوض کن.** رمز به‌صورت هش‌شده در
دیتابیس می‌ماند. کلید سرویس قیمت هم از همان‌جا وارد می‌شود — برای هیچ‌کدام
لازم نیست به فایل دست بزنی یا برنامه را بالا و پایین کنی.

```bash
docker compose down          # توقف
docker compose logs -f       # دیدن لاگ‌ها
```

## اولین قدم‌ها

۱. **ورود اکسل** — فایل را بکش و رها کن. اول **پیش‌نمایش** می‌بینی: چند سطر
   تازه است، چند تا تکراری، و آیا حساب تازه‌ای ساخته می‌شود — همه **قبل از
   اینکه چیزی ثبت شود**. جمع واریز/برداشت هم با سرصفحهٔ خودِ فایل مقایسه
   می‌شود تا مطمئن شوی درست خوانده شده.

۲. **تنظیمات ← حساب‌ها و نام‌های «خودم»** — نام، کارت و شبای همهٔ حساب‌هایت
   را اضافه کن. **مهم‌ترین تنظیم برنامه است**: انتقال بین حساب‌های خودت خرج
   نیست. نام و شبای حسابی که واردش می‌کنی خودکار اضافه می‌شود.

۳. **صف بررسی** — قلب برنامه. فایل بانک **نام فروشگاه را نمی‌دهد**، فقط
   شمارهٔ پایانه. اینجا تراکنش‌های بی‌دسته بر اساس شناسه گروه و به‌ترتیب
   مبلغ مرتب می‌شوند. یک بار برچسب می‌زنی، همهٔ تراکنش‌های گذشته و آیندهٔ آن
   شناسه خودکار دسته‌بندی می‌شوند.

۴. **انتقال بین‌بانکی** — اگر بیش از یک بانک وارد کرده‌ای، اینجا جفت‌های
   پیداشده را تأیید کن تا یک جابه‌جایی دو بار شمرده نشود.

## قابلیت‌ها

**فهمیدن اینکه پول کجا رفت**
- دسته‌بندی خودکار با موتور قانون + یادگیری از برچسب‌های خودت
- تحلیل هدررفت: خرج‌های تکرارشونده و اشتراک‌ها با هزینهٔ سالانه، جمع
  خردخرجی‌ها، جهش ماه‌به‌ماه هر دسته
- بودجهٔ ماهانه برای هر دسته با نوار پیشرفت
- سه چیزی که آمار را از غلط‌شدن نجات می‌دهد: **انتقال بین حساب‌های خودم**،
  **حوالهٔ برگشتی**، و **کارمزدِ سطر جدا** — همه خودکار جفت و کنار گذاشته
  می‌شوند
- **تعهدهای ثابت جدا از هدررفت**: قسط وام و اجاره تکرارشونده‌اند ولی
  نمی‌شود قطعشان کرد، پس در جدول جدا می‌آیند و عدد هدررفت را متورم نمی‌کنند

**مخاطبین**
- شماره کارت، شبا، سپرده و پایانه را از داخل تراکنش ذخیره کن
- دستهٔ پیش‌فرض **جدا برای هر جهت**: «از این مخاطب پول بیاید حقوق است» ولی
  وقتی به او پول می‌دهی می‌تواند چیز دیگری باشد

**وام و قرض**
- وام: جدول اقساط خودکار، آپلود اسکرین‌شات رسید، یادآوری سررسید،
  **وصل خودکار اقساط به تراکنش بانکی**، و تشخیص خودکار وامِ دریافتی
- قرض: دفتر طلبکاری و بدهکاری با بازپرداخت‌های جزئی

**درآمد — با تأیید خودت**
- هر واریزی درآمد نیست: وام، پس‌گرفتن قرض و پول دیگران هم واریز می‌شوند
- صف «درآمد؟» واریزی‌های بلاتکلیف را بر اساس طرف‌حساب گروه می‌کند؛ با یک
  تصمیم، همهٔ واریزی‌های آن شخص تعیین‌تکلیف می‌شوند
- تا تصمیم نگیری، در هیچ آماری شمرده نمی‌شوند
- اگر برای مخاطبی «دستهٔ دریافت» بگذاری، واریزی‌های بعدی‌اش خودکار درآمد می‌شوند

**لیست نیازها**
- چیزهایی که لازم داری با برآورد قیمت، ددلاین، اولویت، لینک و عکس
- تیک «خریدم» و وصل به تراکنش بانکی → **قیمت واقعی در برابر برآورد**

**بازار و دارایی**
- قیمت طلای ۱۸ عیار، طلای ۲۴ عیار، دلار و یورو با تاریخچه
- سبد دارایی با ارزش روز و سود/زیان
- هشدار قیمت با آستانه‌ای که خودت می‌گذاری
- نیازمند `BRSAPI_KEY` در `.env`؛ بدون آن این بخش خاموش می‌ماند و بقیهٔ
  برنامه کامل کار می‌کند

**پشتیبان‌گیری**
- از داخل تنظیمات: دیتابیس + فایل‌های خام، با دانلود مستقیم
- یا از خط فرمان: `./backup.sh`

## سرویس قیمت

پیش‌فرض **BrsApi.ir** است: رایگان، تا **۱۵۰۰ درخواست در روز**.
کلید رایگان: <https://api.brsapi.ir/Panel/panel.html>

| | نوسان | **BrsApi** |
|---|---|---|
| سهمیهٔ رایگان | ۱۲۰ در ماه | **۱۵۰۰ در روز** |
| هزینه | اشتراک ماهانه | رایگان |
| طلای ۲۴ عیار | ندارد | دارد |
| درصد تغییر | باید حساب شود | آماده می‌دهد |

اگر کلید نوسان داری، با `MARKET_PROVIDER=navasan` می‌شود سوییچ کرد.

برنامه هرگز از سهمیه رد نمی‌شود:
- همهٔ قیمت‌ها **در یک درخواست** گرفته می‌شوند، نه یکی‌یکی
- تاریخچه **یک سال را در یک درخواست** می‌گیرد → یک‌بار برای همیشه
- شمارندهٔ محلی قبل از هر فراخوانی چک می‌شود؛ اگر سهمیه ته بکشد درخواست
  **زده نمی‌شود** و قیمت‌های ذخیره‌شده همچنان کار می‌کنند
- هر قیمتی که یک‌بار گرفته شد لوکال می‌ماند — تاریخچه رایگان انباشته می‌شود

> **چرا منبع خارجی جایگزین نمی‌شود:** سرویس‌های خارجی نرخ *رسمی* ریال را
> می‌دهند (حدود ۴۲٬۰۰۰) نه بازار آزاد. برای طلا و سکه هم حباب داخلی وجود
> دارد که از قیمت جهانی طلا در نمی‌آید.

> **این برنامه مشاور مالی نیست.** بخش بازار فقط دادهٔ توصیفی نشان می‌دهد —
> تغییر قیمت، دامنه، نوسان و میانگین متحرک — و عمداً هیچ سیگنال خرید/فروش یا
> پیش‌بینی قیمتی نمی‌دهد.

## توسعه

```bash
docker compose run --rm --entrypoint pytest backend   # ۸۰ تست
docker compose logs -f backend
```

ساختار:

```
backend/app/
├── importers/     آداپتور هر بانک (saman.py، melli.py) + registry
├── services/      normalize، jalali، extract، categorize، links،
│                  analytics، loans، backup
│   └── market/    base + brsapi + navasan + service (چند-provider)
├── models/        SQLAlchemy
└── api/routes/    FastAPI
frontend/src/
├── lib/theme.tsx  توکن‌های رنگ و دارک مود
├── components/    Shell، motion، ui
└── pages/         داشبورد، صف بررسی، مخاطبین، قرض، بازار، …
```

**تم:** هشت تم قابل انتخاب (خنثی، زمردی، آبی نفتی، کهربایی، بنفش، گلبهی،
فیروزه‌ای، تک‌رنگ) هرکدام در حالت روشن و تیره، از صفحهٔ تنظیمات.

**قاعدهٔ رنگ:** هیچ کامپوننتی هگز خام نمی‌نویسد. همهٔ رنگ‌ها از توکن‌های
معنایی `index.css` و `lib/themes.css` می‌آیند.

**هشت تم** (خنثی، زمردی، آبی نفتی، کهربایی، بنفش، گلبهی، فیروزه‌ای، تک‌رنگ)
هرکدام در حالت روشن و تیره — از تنظیمات انتخاب می‌شوند. سبز=درآمد و
قرمز=هزینه در همهٔ تم‌ها ثابت است، چون معنا دارند نه سلیقه. هر ۹۶ جفت
متن/زمینه کنتراست ≥ ۴.۵:۱ دارند.
